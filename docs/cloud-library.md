# 図解ライブラリ：Phase 11B-1

既存ローカルフォルダ機能と、図解ライブラリをTabViewで分離する。図解ライブラリの「クラウド（モック）」は同梱資料をAPI契約に従って取得する実装であり、ネットワークAPIや実S3への接続ではない。

## APIと認証の境界

共通契約はdiagram-design-systemの `docs/viewer-api.md`（2026-10-09 Phase 11A）。CloudLibraryAPIは一覧・検索・cursor・詳細・形式／ページ指定access-url・ダウンロードを分離。MockCloudAPIとHTTPSCloudAPIが同じprotocolを実装する。旧API詳細のJSON input/validationを表示対象から除外し、detailにContent-Typeがない場合は許可形式の固定MIMEを使う。取得grantのMIME・サイズ・ハッシュ・ファイル名・有効期限をdetailと照合する。

HTTPSCloudAPIは将来の接続用アダプターで、現在のアプリは使わない。APIはHTTPS・Bearerのみ、AWSキーなし。token providerを注入し、署名付きartifact取得にはAPIトークンを付けない。署名URLの取得先hostは設定側の許可リストに限定し、redirect・cookie・URLCacheを無効化する。JSONは1 MB、成果物は20 MB未満に限定し、ストリームが期待サイズを超えれば停止する。署名URLはメモリのみでindexへ保存しない。

OIDC Authorization Code＋PKCE、Keychain、更新／ログアウト、issuer/subject別保存領域、公開HTTPS APIの設定は次工程。アプリにパスワード交換や長期キーを追加していない。公開サービスは今回作成しない。

## ファイル管理

- 一時閲覧：Library/Caches/DiagramLibrary。ID・版・形式・PNGページ・SHA256を使う名前。キャッシュ削除対象。
- 永続保存：Library/Application Support/DiagramLibrary。index.jsonと成果物を原子的に保存。アプリ削除時はOSにより削除される。iOSバックアップの標準動作に従う。
- indexには資料ID・版・タイトル・形式・ページ・サイズ・SHA256を保存。ローカル絶対パス・署名URL・トークンは保存しない。パスをAPIのファイル名から直接構成しない。
- 書込前とオフラインopen前にサイズ／SHA256を検査する。同じID・版・形式・ページの異なるハッシュは上書き拒否する。旧版は別ファイルとして保持する。
- ファイル保護はcompleteUntilFirstUserAuthentication。永続保存と一時キャッシュは別のrootで、キャッシュ削除は永続保存へ影響しない。

保存単位は形式／PNGページごと。全形式・全ページの一括保存、保存資料削除UI、容量上限／LRU、自動更新は今回未実装。右上の検索アイコンを押すと検索欄を表示し、すべて／タイトル／タグで対象を切り替える。入力中に取得済み一覧をローカルで絞り込む。保存済みも同じ検索を利用する。前後の空白を除き、大文字小文字を区別しない部分一致。現在のモックは全件取得で、将来の実API接続時は未取得ページを含む検索方式を別途設計する。

## 表示と互換性

CloudFileStoreから取得したローカルURLをOpenedDocumentへ渡し、既存DocumentViewerを再利用。PDF→PDFKit、PNG→画像ビューアー、SVG→既存のscript／remote resourceを制限したWKWebView、PPTX→Quick Look。PDF/PPTXは全資料、PNGは選択ページ。SVGはモックの単一図解だけで、Phase 7.6のプレゼン保存対象へ追加していない。

iOS 17.4 Quick LookではRAG PPTXの日本語書体・折り返しがPowerPoint/PDFと異なった。形式を取得して開く機能は動作するが、PPTXのレイアウト一致を保証しない。資料詳細でPDFを案内する。生成側の修正は別Development課題に分離する。

モック：RAG8枚のPDF/PPTX/ページPNGはPhase 7.5の公開可能サンプル。SVGは外部参照なしの小さな独自テスト図。原資料や顧客情報・認証情報を同梱しない。ID・版・SHA256を元成果物から維持している。モック版を本番へ切り替えるときはモック／本番データの識別と移行方針を決める。

## 登録資料の容量

図解ライブラリの右上「その他」→「登録資料の容量」で、全ライブラリの最新版の件数・成果物合計容量・取得完了日時を確認できる。初回表示と「更新」で認証済み既存APIの全一覧ページと各最新版詳細を取得する。検索・保存済み表示・端末ダウンロード状態には依存しない。PDF/PPTX/全ページPNG/SVGを合算し、未知形式の管理ファイルは既存detail decodeで除外する。旧版・管理ファイル・一時キャッシュは含まない。モック接続ではサンプル集計と明示する。

集計中の部分合計は表示しない。失敗時は未取得または前回値とその日時を表示し、画面を閉じれば処理をキャンセルする。公開APIの毎秒1リクエスト制限に合わせて通信間隔を1.1秒確保する（他の通信との競合時は再更新が必要になる場合がある）。資料数に比例して詳細取得が増えるため、将来大量利用ではサーバー集計へ移行を検討する。成果物本体は取得しない。API側のcatalogキャッシュは最大60秒、取得中のライブラリ更新を固定するスナップショットはない。更新日時は集計完了時刻であり、S3の厳密な計測時刻ではない。

S3全体はAWS CLIの`aws s3 ls s3://diagram-design-system-676643701781-apne1/ --recursive --human-readable --summarize`で現在のオブジェクト合計を別途確認する。アプリの最新版選択と異なり旧版フォルダや管理ファイルも含む。S3バージョニングの非現行版・未完了multipartはこの値に含まれない。

typeによる分類：presentation/旧未分類はプレゼン資料、illustrationと旧4図解typeは図解ライブラリ。ページ数で分類しない。2タブのCloudOIDC共有、PNG/PDFの既存保存/閲覧を利用。[検証](illustration-validation.md)。

## 端末キャッシュ優先（2026-10-10）

オンライン閲覧も、同じ資料ID・版・形式・PNGページの永続保存、次にSHA256付き一時キャッシュを探し、サイズとSHA256が一致したファイルを再利用する。未取得・OSによるキャッシュ削除・破損の場合に限り署名URLを取得してダウンロードする。明示保存も取得済みファイルから行う。サムネイルは同じ経路で1ページ目PNG（なければPDF）を再利用する。

詳細情報も資料ID・版ごとに利用者別Caches領域へ保存し、再起動後も再利用する。構造と資料ID・版・type・ページ数・形式を照合し、不正な詳細キャッシュは削除して再取得する。署名URLやトークンはキャッシュしない。同じstoreの同一版への並行詳細要求は共有する。

起動時、アクティブ復帰時、一覧更新・プル更新時に既存一覧APIで最新の版を確認する。新しい版のサムネイルは表示時、資料本体は開く時に取得する。検索時の一覧取得は維持する。API側の最大60秒catalogキャッシュにより最新版反映に遅れがあり得る。開いている資料はその版を保持し、閉じて最新のカードを開くと新版になる。常時ポーリングや全形式の先行ダウンロードは行わない。

旧版の保存済み資料は維持し、自動上書き・自動削除は行わない。一時キャッシュ削除で詳細情報と一時成果物を削除し、永続保存は残す。OSが一時キャッシュを削除した場合も再取得する。容量上限／LRUは未実装。再起動時は版別詳細とSHA256照合済みの端末ファイルから一覧を復元する。通信失敗時は端末で取得済みの形式だけを閲覧候補にする。保存済み資料は通常一覧に統合し、通信がない場合も表示・閲覧する。利用者別領域とログアウト時の認証画面への切替は既存仕様を維持する。

検証：[キャッシュ検証](cache-validation.md)。

端末内の非表示：資料カードから非表示にし、「非表示の資料」から戻せる。通常/保存済み一覧に適用し、利用者別保存領域に維持。クラウドへの変更要求なし。[仕様](local-hidden-documents.md)。

## 一覧UIの簡素化（2026-10-10）

プレゼン資料・図解ライブラリの検索を右上の虫眼鏡アイコンへ移動。開いている間だけ入力欄・検索対象を表示し、閉じると検索条件を解除する。見出しは小さい表示へ変更。「すべて／保存済み」切替を廃止し、クラウド一覧と端末保存資料をID・版で重複除外して一つの一覧へ統合。保存した旧版も保持し、クラウド一覧にない保存版は保存した形式だけで通信なしに開く。カードの保存状態と閲覧中の保存操作はブックマークアイコンで表示し、VoiceOverには保存状態・操作名を伝える。資料ごとの保存解除は未対応。「その他」→「端末の資料をすべて削除」で確認後、両クラウドライブラリの現在の利用者の保存済み資料と一時キャッシュを削除できる。S3正本・ローカル資料タブの元ファイル・まとめ・非表示設定は維持する。非表示・分類・認証は維持。

検証は[UI簡素化](ui-simplification.md)。

閲覧画面は中央の再生／全画面ボタンから開始する。一枚図は縦横比に合わせて向きを選ぶ。[仕様・検証](reader-start-button.md)。

図解の関連ページは端末内の「まとめ」に登録して、1カードから順に読める。作成・順番・保存・解除とクラウド境界の正本は[図解のまとめ](diagram-collections.md)。

## 認証エラーからの復帰

「認証が必要です。再ログインしてください。」の一覧・閲覧エラーに「ログインし直す」を表示する。「その他」からも直接再認証できる。ログアウトを経由せず認証ブラウザーを開き、成功後に両クラウドタブの一覧と閲覧状態を作り直す。同じ利用者の端末コピー・非表示・まとめ設定は保持し、別利用者は既存の利用者別保存領域へ切り替わる。失敗・キャンセル時は既存コピーを削除せず、再試行できる。
