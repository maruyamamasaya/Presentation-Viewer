# 横向きの資料一覧

2026-10-13。表紙の見た目で資料を探す用途を優先し、iPhoneの横向き一覧を基本3列に統一した。

- 対象：プレゼン資料、図解（まとめ・非表示一覧を含む）、ローカル資料。
- GeometryReaderの表示領域が横長で、端末種別がphoneの場合に適用。縦向きとiPadは既存の自動列数とカード表示を維持。
- 表示幅600pt未満、またはDynamic Typeのアクセシビリティサイズは2列。
- 横向きの列間隔/行間隔は12pt。クラウドカードの内側余白は6pt、内容間隔は8pt。表紙は既存の16:9とscaledToFitを維持し、タイトルは2行まで。
- ローカル資料の横向き表紙枠は16:9、画像内側余白は0。元画像の縦横比は維持し、切り抜かない。縦向きは従来の4:3枠と8pt余白。
- 既存の「更新あり」・資料操作メニューを維持。保存マークの除去を戻さない。

Windowsのverify_project.pyとgit diff --check合格。構造検査はSwiftコンパイルやレイアウト品質の保証ではない。Macのビルド/XCTest、実機更新、縦横回転・3列/2列・長いタイトル・表紙視認性の目視は未実施。
