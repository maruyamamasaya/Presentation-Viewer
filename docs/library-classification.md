# 資料のグループ・タグ

2026-10-13。プレゼン資料と図解ライブラリの上部に「すべて／仕事／私用／その他」と横スクロールのタグ切替を追加。グループとタグはAND条件、検索とも併用する。未分類はその他。各資料の「…」または長押しから編集し、タグは1件ずつ自由入力・削除できる。保存時の未追加入力も反映。前後空白と大文字小文字だけの重複を除去する。既存タグは初期値とし、編集後は端末設定を優先する。

まとめ内の資料はまとめメニューの「資料のグループ・タグ」から個別編集。グループ・タグの絞り込み中はまとめの資料を個別カードで表示し、まとめの読む順番は変更しない。検索は端末へ取得済みの一覧を対象にし、未取得ページは「さらに表示」で追加する。自由タグがサーバー検索で除外されることを避ける。

利用者別CloudFileStoreのApplication Supportにclassifications.jsonを原子的に保存。資料IDで紐づけ、全版で共有。通信不要で編集し、再起動・キャッシュ削除・端末資料削除後も保持。他端末同期なし。ローカル資料タブの外部ファイルは今回の対象外。AWS/API変更なし。

Windows検証：python tools/verify_project.pyとgit diff --check合格。永続化・清掃後維持・新版引継ぎ・利用者領域分離・空タグへの更新・保存失敗のXCTestを追加。WindowsではSwiftコンパイル／XCTestを実行できず、Simulatorの画面・横向き・Dynamic Type・絞り込み操作と実機反映は未実施。
