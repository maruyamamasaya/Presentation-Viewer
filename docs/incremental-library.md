# スクロール読込と即時復元

2026-10-17。プレゼン資料・図解ライブラリ共通。通常の「さらに表示」を廃止し、末尾が見えた時に次のページを自動取得する。二重取得を防ぎ、失敗時は既存一覧とカーソルを保持して再試行を表示する。検索・分類で表示が空になる場合も末尾の読込を進める。

取得した一覧を利用者別に端末保存し、起動時は資料本体の検証やネットワーク応答より先に復元する。前回認証した保存領域のハッシュだけを接続設定別に記録し、ログイン復元ができない場合もその端末資料を閲覧できる。明示ログアウトでこの参照を消す。クラウド取得には従来どおり認証・認可が必要。初回利用や未取得の資料本体には通信が必要。

一覧更新は独立した状態で処理し、端末資料を開く操作を妨げない。取得済み形式を優先して開く。起動・復帰・下引き・管理メニューで最新一覧を取得し、新版は既存の「更新あり」から取得する。更新失敗時に既存一覧を消さない。

一時キャッシュは両ライブラリ・利用者別領域を合算して5,000,000,000バイト（5GB）を上限とする。書込前と一覧復元時に古いファイルから整理し、本体の利用時に日時を更新する。同時書込も排他制御する。資料本体・詳細・一覧を含む。「アプリ内に保存」の永続コピー、ローカル資料タブ、分類・非表示・まとめ設定は自動整理の対象外。OSも一時キャッシュを削除できる。

検証：XCTestに一覧のみの復元・通信失敗時の保持、ページ追加の重複排除と失敗後再試行、別利用者領域も含む小容量上限での削除・永続領域維持を追加。最終実行結果は本書末尾に記録する。実通信・実機操作は別確認。
