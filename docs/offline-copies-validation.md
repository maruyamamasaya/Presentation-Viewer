# 端末の一時コピーと削除

2026-10-12 JST。ユーザー依頼：S3を正本として端末へ一時保存し、オフラインで即座に閲覧でき、端末をクリーンにできる機能を実装。

既存の利用者別保存、SHA256照合、版別詳細、端末優先取得を維持。起動時は詳細キャッシュから照合済みの本体がある資料を一覧復元し、一覧通信失敗時も保存済み資料とともに表示する。オフライン時の閲覧候補は実在・照合済み形式に絞る。オンライン一覧成功時は通常の最新版一覧へ戻る。取得していないページや形式はオフラインで開けない。OSによるCaches削除はあり得るため、確実に残す資料には既存の保存操作を使う。容量上限/LRUや全資料一括取得は追加していない。
