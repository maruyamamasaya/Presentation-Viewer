# 端末優先・更新時のみ表示（2026-10-13）

通常の資料カードは保存/キャッシュ/クラウドの状態マークを表示しない。オンライン一覧の版番号が端末で利用できる版より大きい場合だけ「更新あり」を表示する。オフラインは更新判定をしない。資料IDごとにカードを統合し、通常タップは端末の最新利用可能版を開く。同版の取得済み形式を優先する。新版は更新ボタンで取得・表示し、旧版コピーを保持。旧版が明示保存されていた場合は取得した新版の形式も明示保存する。閲覧中の版は一覧更新で差し替えない。

保存コピー→SHA256検証済みキャッシュ→取得の既存順序を維持。新版判定は不変版番号による。同版ハッシュ不一致は既存の破損/競合処理を維持。版をまたぐファイル差分転送は追加していない。更新は最初に開く形式を取得し、その他の形式/PNGページは利用時に取得する。旧版キャッシュのみの場合も一覧・ページ切替で使えるよう修正。

検証：Windowsのverify_project.py、git diff --check合格。CloudLibraryTestsに端末旧版維持、更新検出、同版再閲覧の追加通信ゼロ、明示新版取得後の表示解消、オフライン非表示の回帰テストを追加。Apple SDKがないためSwiftビルド/XCTest/画面目視/実機反映は未実施。先行プレゼン透過UIの未検証状態も維持。AWS/API変更なし。
