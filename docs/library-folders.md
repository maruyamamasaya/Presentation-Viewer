# iOSのフォルダと複数選択

2026-10-17。プレゼン資料/図解ライブラリの共通機能。外部ファイルを扱うローカル資料タブは既存のまま。

## 操作

iPhone右下のライブラリメニュー→本棚で、すべての資料/未整理/フォルダを選ぶ。フォルダは階層パス表示し、親を選ぶと子孫の資料も表示。iPadは一覧上にも本棚操作を表示する。「フォルダを作成」は選択フォルダの子（全て/未整理なら最上位）へ追加。

「資料を選択」→複数カードをタップ→上部「フォルダへ移動」→移動先を選ぶ。「すべて選択」は取得済みの現在の表示条件に合う資料のみで、サーバー未取得の全資料を暗黙に含めない。「未整理」で分類解除。「完了」で選択終了。フォルダを切り替えると選択解除、検索等で表示から外れた選択IDも解除。保存失敗時は選択と元の分類を保持し、エラーを表示する。

選択中/フォルダ内ではまとめを個別資料として表示する。まとめのUUID/名前/読む順番と取得ファイルは変更しない。全てへ戻り選択終了すると従来のまとめ表示へ戻る。分類・タグ・検索はフォルダとAND条件。既存の非表示資料は通常の選択対象外。

フォルダ解除は子孫も解除し、その分類を未整理へ戻す。原本/保存済みファイル/タグ/まとめは削除しない。画像設定・フォルダ名変更・順序編集・ドラッグは今回追加していない。

## 保存・互換

共有パッケージOrganizationState<CloudDiagram>を利用し、既存の利用者別Application Supportにorganization.jsonを原子的/保護属性付きで保存する。資料IDは既存iOSと同じ小文字で版に依存せず分類。保存先はクラウド/図解タブで共有し、タブ復帰でも再読込する。キャッシュ削除/端末資料削除の対象外。別利用者のフォルダ/分類を混ぜない。classifications.json、collections.json、index.jsonと本体はそのまま維持し、一括移行や既存フォルダ推測は行わない。同期/AWS/API変更なし。
