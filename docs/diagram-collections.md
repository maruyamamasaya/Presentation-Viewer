# 図解のまとめ

2026-10-10。図解ライブラリの「その他」→「図解をまとめる」で、名前を付け、関連する図解を選ぶ。選んだ順を初期の読む順番とし、上下ボタンで並べ替えられる。保存すると一覧ではまとめのカードを一つ表示し、そのまとめに含まれる個別カードを隠す。メニューから名前・内容・順番を編集し、まとめだけを解除できる。解除後は個別カードへ戻り、取得ファイルは保持する。

## 閲覧と保存

まとめカードを開くと、各資料のPNGをページ順に並べ、PNGがない資料はPDFで開く。前後ボタンで別資料へ移動し、全画面の画像閲覧でも移動を維持する。下部に現在位置と総数を表示する。PDFのみの場合はPDF内のページ移動をPDFKitが担当し、外側の前後ボタンは前後の資料へ移動する。そのため表示数はPNGページまたはPDFファイルの数。PDF間の切替では通常閲覧へ戻る。

ブックマークはまとめで使う全PNG（PNGなしならPDF）を順に永続保存する。全形式の保存ではない。途中失敗で保存済みファイルは残し、全件保存済みと表示しない。保存済みのまとめはネットワークなしで読める。保存していない資料を含む場合は通信が必要。キャッシュの正常性・サイズ・SHA256・署名URL/認証は既存経路を使用する。

## データと認証の境界

`CloudCollection`はUUID、タイトル、順序付きの資料スナップショットだけを保持。資料ID単位で所属させ、取得済み一覧と保存記録に同じIDの版が複数ある場合は最大の版を採用する。開いたまとめはその版と順番を維持する。検索結果・ページネーションで未取得の資料は保存時のスナップショットへフォールバックする。自動的に同名資料を結合しない。タイトル1〜120文字、資料1〜100件、ID重複なし、PNG/PDFを持つ図解に限定する。

`CloudFileStore`が利用者別のApplication Support領域に`collections.json`を原子的に保存する。キャッシュ削除・再起動で維持し、利用者/モックの保存領域を分離。同期・クラウド書込・AWS/API変更はない。まとめの解除は設定だけを削除し、元資料・ファイル・旧版を保持。非表示の資料はまとめからも除外し、再表示で元の順番へ復帰する。
