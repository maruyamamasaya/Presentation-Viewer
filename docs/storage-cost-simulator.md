# 保存料金シミュレーション

2026-10-15。両クラウドライブラリの管理メニューから「保存料金シミュレーション」を開く。既存認証メタデータAPIで最新版の成果物容量を集計し、1か月保持した保存費を算出する。本体のダウンロードなし。

初期条件：東京S3 Standard参考単価0.025 USD/GiB・月、150円/USD、税10%。各条件と容量は画面で変更可能。単価は固定参考値で自動更新しない。AWS公式料金へのリンクを用意。50 TiB以下の単一料金帯に限定し、負値/非有限値/税100%超を拒否。100 GiBは412.5円/月。実請求・月間累積・日割り・無料枠・通信/API/認証料金を含まない。

既存APIの制約：最新版のPDF/PPTX/PNG等のみ。旧版・S3非現行バージョン・管理ファイル・クラウドゴミ箱は含まない。iPhone内の非表示資料は集計対象。S3全体の使用容量とは異なる。原本や過去版を含む総量が既知なら手入力する。AWS/API/権限を変更していない。

更新成功ごとに容量・取得時料金・日時を利用者別CloudFileStoreのstorage-cost-history.jsonへ原子的保存。最大365回。容量と料金の2グラフを表示し、過去の料金を現在の条件で再計算しない。サンプル/本番は既存の保存namespaceで分離。端末コピー削除でも履歴を保持する。手入力は履歴へ追加しない。バックグラウンド計測なし。初回は更新ボタンで集計する。取得失敗では前回値を保持し、保存失敗と区別して表示。
